# ⚡ State Power Corporation - Electricity Billing Portal
--
A desktop GUI billing software built using **Java Swing** and **AWT**. It simulates real-world utility billing with slab rates, fixed charges, regulatory duties, live consumption calculation, and PDF/Print invoice generation.

---

## ✨ Features
- 🏢 **Multi-Connection Support:** Domestic (Residential) and Commercial (Business) slabs.
- ⚡ **Auto Units Calculation:** Real-time calculation from previous and current meter readings.
- 🧾 **HTML Invoice Preview:** Structured tax invoice breakdown with live date/time and auto-incrementing bill numbers.
- 🖨 **Print & PDF Export:** One-click receipt printing or export via system print dialog (`Ctrl + P` / `Ctrl + S`).
- 📊 **Rate Card & History:** Built-in modal for active tariff rates and recent session transaction history.
- ⌨ **Keyboard Shortcuts:** Faster operations using `Enter` (generate) and `Esc` (clear).

---

## 🛠 Tech Stack
- **Language:** Java (JDK 8+)
- **GUI Framework:** Java Swing & AWT
- **Styling:** Custom Component Architecture, Modern Color Palette & HTML Formatting
